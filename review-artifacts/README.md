# オフライン実装のレビュー資料

ここにある候補コードは、`apps/web/src/` に採用済みの実装ではない。
テスト結果の報告だけで採用せず、対象コードのハッシュ・実際の内容・親による
レビューと再検証を確認する。

## 過去の資料

`note-*`、`storage-*`、`user-cache-suspension-v7` は、以前の
「一時実装 → 候補コピー → 実装復元」方式で残った監査資料である。
一部では候補の保存失敗や過去資料の変更があり、記載された検証結果と
現在のファイル内容が一致するとは限らない。これらを新しい実装へ
無条件にコピーしない。

特に `user-cache-suspension-v7` のソースファイルは、テスト済み候補ではなく
変更前の実装だったことを確認済み。詳細はその `validation.md` に記録している。

## 新方式

`user-cache-suspension-v8` 以降は候補ファイル自体を直接編集し、
`apps/web/scripts/check-offline-candidate.mjs` で検証する。
サブエージェントは `apps/web/src/` を編集・復元しない。
候補の変更は新しいハッシュとして記録し、再検証する。

意思決定は `docs/offline-pwa-decisions.md` に集約する。
候補固有の追加判断は候補内の `decisions.md` に記録し、親が集約する。
候補が不採用になっても、理由と証拠は履歴へ残す。
